# Security Policy

## Supported Versions

Only the current main branch and latest deployed release receive active security updates.

| Version | Supported          |
| ------- | ------------------ |
| Main (`v0.0.1`) | :white_check_mark: |
| Sub-branches | :x:                |

## Reporting a Vulnerability

We take the security of Marga Adventure seriously. If you discover a security vulnerability or potential threat in this application:

1. **Do NOT open a public GitHub issue** detailing the vulnerability.
2. Report the vulnerability privately to the project security maintainers at:
   - **Security Contact:** `[SECURITY_CONTACT_EMAIL_PLACEHOLDER]` *(Please configure primary security email in repository settings)*
3. Include the following information in your report:
   - Summary and type of vulnerability (e.g., XSS, token leakage, CSRF, broken access control)
   - Step-by-step proof of concept or instructions to reproduce the issue
   - Potential impact and affected components/endpoints
   - Any proposed fix or remediation (if available)

## Responsible Disclosure & Response Process

- **Acknowledgement:** We aim to acknowledge receipt of security reports within 48 hours.
- **Assessment & Triage:** Our engineering team will assess the report and confirm the vulnerability.
- **Fix & Deployment:** Confirmed vulnerabilities will be patched and deployed promptly.
- **Public Disclosure:** We ask that reporters maintain confidentiality until an official security patch has been released.
